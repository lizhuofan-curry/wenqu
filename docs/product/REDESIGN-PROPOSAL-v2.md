# 问渠 · 前端重设计方案 v2.0

> 目标：从"通用蓝白后台"升级为**有品牌记忆点、有质感的学习空间**。
> 本文档为设计方案与实施计划，供评审后再动代码。

---

## 一、现状诊断

### 1.1 技术与结构现状

| 项目 | 现状 | 问题 |
|---|---|---|
| 样式组织 | 单一 `styles.css`，3431 行 | 无分层、无令牌体系，改动风险高 |
| 设计语言 | 文件内存在 **两套主题**:v.1 蓝白（前 1493 行）+ legacy 暗夜墨金（`@layer legacy`，后 1900+ 行） | 互相覆盖、死代码多、命名冲突（`.sidebar`、`.hero-panel` 等被定义两次） |
| 字体 | Inter + 系统黑体，品牌处用 `STKaiti/KaiTi` | 楷体仅点缀出现，未形成排版系统；无 Web Font 加载策略 |
| 色彩 | 蓝白主色 `#3975f6`，语义色散落在各处硬编码 | 无统一 token,hover/focus 态不一致 |
| 主题 | 明/暗双主题已具备 | 暗色是浅色的机械反转，没有独立设计 |
| 品牌 | "问渠"出自朱熹《观书有感》 | 视觉与"书房、源头活水"的意象完全脱节 |

### 1.2 体验层问题

- **首页 Hero** 信息层级平：标语、按钮、装饰轨道图权重相近，没有"一眼焦点"。
- **卡片语言单一**：所有面板都是"白卡 + 1px 灰边 + 轻投影"，资料库、洞察、档案页读起来像同一个页面。
- **陪读流程（StudyFlow）** 是全产品最有仪式感的部分（地图 → 双轨 → 回忆 → 复述 → 诊断），但视觉上和普通页面没有区别，缺少"进入书房"的沉浸感。
- **微交互缺失**：无页面过渡以外的动效，按钮、卡片、进度反馈都偏"静态"。

## 二、设计方向（三选一，推荐 A)

### 方案 A: 「纸上书房」—— 东方人文 × 现代编辑器 ⭐ 推荐

**一句话**：像一本装帧考究的现代杂志 + 一间安静的深夜书房。

- 浅色模式不是"白"，而是**宣纸暖白**(`#faf8f3`)；暗色模式不是"灰蓝"，而是**墨色**(`#16181d`)，两套主题各自独立设计。
- 主色放弃 SaaS 蓝，改用**黛蓝（靛青） `#2f4b7c` + 朱砂点缀 `#c0473d` + 金 `#b8912f`**，取自传统书房色谱。
- 标题用**思源宋体（Noto Serif SC)**，正文用 Inter + 苹方/思源黑，数字用等宽字体（呼应"证据、页码"的产品理念）。
- 装饰元素：细线框、印章式角标、竖排小字、页码式编号 —— 克制使用，只在 Hero、章节标题、档案页出现。
- **适合**：强化"问渠"品牌独特性，与市面上所有 AI 学习产品拉开差距。

### 方案 B: 「静夜思」—— 深色优先的沉浸学习舱

- 深色为主默认主题，大面积深墨蓝黑 `#0e1116`，配合琥珀暖光 `#e8b45a` 模拟台灯氛围。
- 玻璃拟态（backdrop-blur)+ 细腻的内发光，陪读界面做成"聚光灯下的书桌"。
- 风险：深色优先对教育类产品的长文本阅读不友好，浅色模式会变成二等公民。

### 方案 C: 「学院派」—— 现代期刊排版风

- 参考 Linear / Stripe Press / 《纽约客》网站：严格网格、大字号衬线标题、脚注、分栏。
- 浅米白 + 纯黑文字 + 单一强调色，极简、编辑感强。
- 风险：个性弱于 A，与品牌中文语境的连接不如 A 自然。

> **建议选 A**:legacy 代码里那套墨金宋体遗产说明产品本来就有这个基因，方案 A 是把它做对、做完整，而不是推倒重来。

## 三、设计令牌（Design Tokens)

### 3.1 色彩（方案 A)

```css
/* —— 浅色 · 纸上 —— */
:root {
  --paper:        #faf8f3;   /* 页面底：宣纸 */
  --paper-warm:   #f3efe6;   /* 次级底 */
  --ink:          #1c2333;   /* 主文字：墨色 */
  --ink-soft:     #5a6478;   /* 次要文字 */
  --ink-faint:    #9aa2b1;   /* 辅助文字 */
  --indigo:       #2f4b7c;   /* 主色：黛蓝 */
  --indigo-deep:  #223a63;
  --cinnabar:     #c0473d;   /* 强调：朱砂（仅关键动作/错因） */
  --gold:         #b8912f;   /* 点缀：金（成就、掌握度） */
  --bamboo:       #4a7a6a;   /* 成功：竹青 */
  --line:         #e4ded0;   /* 分隔线 */
  --card:         #ffffff;
  --shadow-card:  0 1px 2px rgba(28,35,51,.04), 0 8px 24px rgba(28,35,51,.06);
}

/* —— 深色 · 夜读 —— 独立设计，非反转 */
:root[data-theme="dark"] {
  --paper:        #16181d;   /* 墨 */
  --paper-warm:   #1c1f26;
  --ink:          #e8e4da;   /* 暖白，不是纯白 */
  --ink-soft:     #a39e92;
  --indigo:       #8fa8d0;   /* 夜灯下的黛蓝变浅 */
  --cinnabar:     #d4695f;
  --gold:         #cfa64a;
  --card:         #1e2129;
  --line:         #2c303b;
}
```

### 3.2 排版

| 角色 | 字体 | 规格 |
|---|---|---|
| 展示标题 | Noto Serif SC 600 | clamp(28–44px),字距 -0.02em，行高 1.25 |
| 页面标题 | Noto Serif SC 600 | 24–28px |
| 正文 | Inter + PingFang/思源黑 | 14–15px，行高 1.75 |
| 证据/数据/编号 | JetBrains Mono / ui-monospace | 12–13px（页码、公式、掌握度） |
| 眉题 eyebrow | 11px · 700 · 字距 0.16em · 大写/竖排可选 | 黛蓝或朱砂 |

字体加载：思源宋体走 Google Fonts(woff2,`font-display: swap`)，只加载 400/600 两个字重。

### 3.3 形状 / 材质 / 动效

- 圆角：卡片 `14px`、按钮 `10px`、芯片 `999px`（比现在的 18px 更收敛、更"纸张")。
- 阴影：极浅双层阴影，深色模式改用 **1px 亮边 + 内阴影** 表达层级。
- 质感细节：页面背景叠加 2% 噪点纹理（SVG feTurbulence,data-URI，一次定义全局复用）；Hero 区可用极淡的"水波纹"SVG 呼应"源头活水"。
- 动效：`150–250ms / cubic-bezier(.2,.7,.3,1)`；页面进入 fade+rise；卡片 hover 上移 2px;**进度条、掌握度圆环用 600ms 缓动**。全部包在 `prefers-reduced-motion` 里。

## 四、页面级改造要点

### 4.1 全局 Shell
- 侧栏 238px → 240px，底色与主区拉开半阶；导航激活态从"蓝底块"改为**左侧 2px 朱砂短线 + 文字加深**，更安静。
- 顶栏搜索框弱化（去边框、只留底线），`⌘K` 保留；通知、主题切换统一为 36px 幽灵图标按钮。
- "问渠 · 取义"卡片保留并升级为侧栏底部的**印章样式**（朱砂色边框、竖排"问渠"二字）。

### 4.2 今日阅读（Dashboard)
- Hero 重做：左侧大标题（宋体，两行，主句用黛蓝）+ 一段说明 + 主按钮；右侧把现在的"轨道圆环"换成**材料封面卡片叠放 + 今日进度环**，真实信息替代纯装饰。
- 三宫格快捷入口 → **横向"今日三件事"列表**：继续上次 / 待复习错因 / 新资料，每条带预计时长，更有行动感。
- 资料卡加封面色阶系统（按学科/类型映射 6 种纸色），摆脱渐变蓝紫。

### 4.3 陪读流程（StudyFlow)—— 重点打造
- 进入学习即切换为**沉浸式布局**：隐藏侧栏，顶部只留进度步骤条（步骤改为"一 二 三 四 五"中文数字 + 宋体）。
- 双轨跟读：严格轨白底细框（期刊感），陪读轨暖米底（便签感），两栏视觉性格分明。
- 复述环节：居中窄栏（max 720px)，像一张稿纸；字数进度做成页面底部的细墨线。
- 诊断结果：掌握度圆环改**描边动画**；错因标签用朱砂色"批注"样式（手写感下划线、便签纸），而非红色警告块——是"批注"不是"报错"。

### 4.4 资料库 / 洞察 / 错因图谱 / 档案
- 资料库：卡片封面 + 底部进度墨线；筛选 pill 改为下划线式 tab。
- 学习洞察：柱状图改细柱（宽度 60%→40%)+ 顶部数值直接标注；掌握环改细环（stroke 6px)。
- 错因图谱：概念节点改"便签 + 细连线"，薄弱点用朱砂虚线圈出。
- 阅读档案：做成**成绩单/书签**样式，每次陪读是一张竖版卡，左侧宋体大字得分。

### 4.5 登录弹窗
- 居中卡片加顶部"问渠"印章；输入框去灰底、只留底线，聚焦时底线变黛蓝 —— 与全站输入语言统一。

## 五、实施计划（建议分四期）

| 期 | 内容 | 产出 | 预估 |
|---|---|---|---|
| **P1 地基** | 删除 `@layer legacy` 死代码；`styles.css` 拆分为 `tokens.css / base.css / shell.css / pages/*.css`;CSS 变量全面替换硬编码色值；接入 Noto Serif SC | 样式架构干净，视觉暂不变 | 0.5–1 天 |
| **P2 令牌与全局** | 落地新 tokens（双主题独立调色）、排版系统、按钮/输入/卡片/标签组件样式；Shell 改造 | 全站气质切换完成 | 1 天 |
| **P3 页面精修** | Dashboard Hero、StudyFlow 沉浸模式、四个子页面按 §四 改造 | 核心体验成型 | 1.5–2 天 |
| **P4 质感收尾** | 噪点纹理、动效系统、掌握环描边动画、空状态插画、暗色模式逐页校对 | 达到"有质感" | 1 天 |

**不改的东西**:React 组件结构、props、API 层、`App.tsx` 状态逻辑全部不动 —— 本次是纯视觉层重构，风险可控，`pnpm check` 全绿即可验收。

**验收清单**
- [ ] `styles.css` 拆分完成，legacy 层删除，无重复选择器定义
- [ ] 全部颜色/字体来自 token，无散落的硬编码 hex
- [ ] 明/暗两套主题逐页截图走查
- [ ] `prefers-reduced-motion` 下所有动效降级
- [ ] 320px / 768px / 1280px 三档响应式无破版
- [ ] `pnpm typecheck && pnpm build` 通过
