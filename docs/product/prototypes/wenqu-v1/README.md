# 问渠 v.1｜产品原型图

> 版本日期：2026-07-27  
> 产品主张：问渠不替你读，而是陪你把知识变成自己的话。

本目录保存由正式 React 前端真实运行后生成的产品原型图，不是脱离代码绘制的静态概念稿。页面均可在应用内实际点击和跳转。

## 交互路径

```text
今日阅读
├── 资料库 → 选择材料 → 开始陪读
├── 学习洞察 → 查看掌握度与建议
├── 错因图谱 → 查看误解 → 开始巩固
├── 阅读档案 → 查看历史诊断
├── 免费注册 / 登录
└── SENet 陪读
    └── 材料地图 → 双轨讲解 → 理解测验 → 用话复述 → 学习诊断
```

## 演示边界

- 公网版本默认使用内置演示数据，无需配置 API 密钥；
- 注册信息只保存在当前浏览器，不会上传到服务器；
- 本地开发模式仍可连接 FastAPI，使用真实 SQLite 档案与材料处理；
- 完整多人账户、云端数据同步与生产隐私协议属于后续上架准备事项。
