# SENet 第一次陪读｜证据笔记卡本地 MVP 内部演练

> 本文件只使用合成笔记、合成账号和合成来源位置，不包含真实用户文字。
>
> 演练验证本地保存、边界和隔离规则能否按约定执行，不验证笔记内容正确性，也不证明学习效果。

## 一、演练前断言

- 只有 `learner_statement` 与 `question_or_hypothesis` 两种内容类型；
- 界面只显示“我的理解”与“待核对”，不存在 `paper_claim` 或 `verified`；
- 正文只来自学习者显式输入，系统不补写、不纠错、不拆分、不生成引用；
- 可选 `source` 只记录创建时的 `label/detail` 等未认证位置快照，不核验正文；
- 笔记不进入课前诊断、正式评分、复述、掌握度、路线或延迟测量；
- 笔记按账号命名空间保存在当前浏览器，不上传、不云同步；
- 导出只包含当前账号的本地笔记与位置快照，不包含秘密或学习评分数据；
- 所有输出不宣称能力、长期掌握、因果提升或论文事实认证。

## 二、18 种合成场景

| # | 合成操作 | 期望结果 | 关键断言 |
|---:|---|---|---|
| 1 | 在 Squeeze 位置保存“我的理解” | 创建 `learner_statement`，快照为 PDF 第 3 页、3.1 节、公式（2） | 标签仍是“我的理解”，不是论文事实 |
| 2 | 在 Excitation 位置保存一个疑问 | 创建 `question_or_hypothesis`，快照为 PDF 第 3 页、3.2 节、公式（3） | 显示“待核对”，不自动回答 |
| 3 | 用户写下与论文一致的完整形状 | 原文保存为“我的理解” | 内容看似正确也不产生 `verified` |
| 4 | 用户写“训练后会永久删掉通道” | 原文保存，不纠错、不润色 | 不静默替换成通道重标定，也不输出标准答案 |
| 5 | 一段正文同时含正确、错误和疑问 | 作为一张用户卡片保存 | MVP 不自动拆成事实、错误和问题 |
| 6 | 正文为空或只有空白 | 拒绝保存并保留编辑状态 | 不生成空卡片或默认文案 |
| 7 | 正文超过 2000 个字符 | 显示确定性长度错误，不写入本地存储 | 不截断后冒充用户原文 |
| 8 | 客户端提交未知 `content_kind` | 拒绝或隔离该记录 | 不按“我的理解”默认展示 |
| 9 | 创建时没有可靠来源 | 保存正文，不保存 `source`，显示“未附原文定位” | 不猜页码、公式或最近章节 |
| 10 | 创建卡片后滚动到另一章节 | 既有快照保持创建时位置 | 导航行为不改写来源快照 |
| 11 | 材料 revision 后续改变 | 保留旧 revision 与旧位置并提示可能变化 | 不自动重映射，也不把快照称为核验证据 |
| 12 | 编辑已存在卡片的正文或类型 | 保留 `created_at`，更新 `updated_at` | 编辑仍不产生正确性或核验状态 |
| 13 | 诊断满分、正式题满分或 confidence 很高 | 卡片列表、标签与类型不自动变化 | 评分和自我把握不升级笔记 |
| 14 | 点击“已理解”、完成路线或打开卡片多次 | 不生成卡片，不修改类型，不写学习证据 | 阅读行为和显式自评不等于掌握 |
| 15 | 账号 A 保存卡片后切换到账号 B | B 的列表、搜索、数量和导出均看不到 A 的卡片 | 账号命名空间隔离；切换时清除内存态 |
| 16 | 同一账号换设备或清除站点数据 | 不承诺恢复卡片 | 界面预先说明仅本机并提供导出 |
| 17 | 账号 A 导出 JSON | 只含 A 的正文、两类标签、位置快照和时间字段 | 不含账号内部键、秘密、隐藏评分、答案、路线或其他账号数据 |
| 18 | 本地存储被手工写入 `paper_claim`、`verified` 或伪造评分字段 | 读取时拒绝或隔离不支持记录，不渲染事实徽标 | 篡改本地 JSON 不能启用未来能力 |

## 三、来源快照专项检查

对内置地图、正文与普通结果页分别创建合成卡片，并检查当前实现提供的快照：

| 位置 | 当前必须匹配的快照 |
|---|---|
| 材料地图条目 | `section_id = map:<key>`，`source.label/detail` 与当前地图条目一致 |
| Squeeze 正文 | `section_id = squeeze`，`label = PDF 第 3 页`，`detail = 3.1 节与公式（2）` |
| Excitation 正文 | `section_id = excitation`，`label = PDF 第 3 页`，`detail = 3.2 节与公式（3）` |
| Scale 正文 | `section_id = scale`，`label = PDF 第 3 页`，`detail = 公式（4）` |
| 普通学习结果 | `section_id = result:<question_id>`，来源复制当前题目结果的 `label/detail` |

每张卡片还必须通过反向断言：即使自由文本定位看起来准确，公开对象和界面也不能出现 `paper_claim`、`verified`、“论文事实”或“已核验”。

以下情况失败闭合，不补值：

- 当前来源没有页码或公式信息，却从相邻章节猜测并补入 `detail`；
- `material_id` 与阅读器当前材料不一致；
- `material_revision` 缺失却被显示为当前 revision；
- 未取得可靠来源却生成更具体的 `source`。

“失败闭合”在本地 MVP 中表示不保存 `source` 或隔离整条不合法记录；不能因此丢弃已通过正文校验的学习者文字，也不能生成更具体的猜测位置。结构化 PDF 页、论文页、公式和 Figure 字段尚未实现，不列为本轮通过项。

## 四、数据与账号隔离检查

至少使用两个合成账号命名空间和三个材料 revision 验证：

1. 创建、读取、编辑、删除、筛选和导出都只访问当前账号命名空间；
2. 切换账号前清除组件内存、搜索结果、数量缓存和当前编辑对象；
3. 本地存储键包含 schema version 与不透明账号命名空间，不含邮箱和令牌；
4. 删除单卡只影响准确的 `id`，重复删除幂等且不误删其他账号卡片；
5. 首版没有“清除全部”入口；未来若增加，必须明确目标账号和不可云端恢复，并要求二次确认；
6. 网络请求检查确认卡片正文、来源快照和导出内容没有发送到 API；
7. 退出后其他账号看不到残留界面；同账号重新登录只恢复同一浏览器内属于自己的数据。

本轮通过账号隔离只能证明测试范围内没有串读，不能把浏览器本地存储称为加密保险箱或可靠备份。

## 五、导出检查

导出文件必须通过：

- UTF-8 JSON 可解析；
- 顶层包含 `schema_version`、`exported_at` 与 `notes[]`；材料标识保留在各条笔记中；
- 两种内容类型、正文、创建时来源快照、`created_at` 与 `updated_at` 往返一致；
- `notes[]` 仅属于当前账号，但文件内不暴露账号命名空间内部键；
- 不包含邮箱、令牌、密码、数据库地址、完整认证对象；
- 不包含课前原始答案、隐藏规则、标准答案、scorer/rubric 实现；
- 不包含正式评分、错因、复述、mastery、路线或其他用户档案；
- 文件名不包含邮箱或其他直接身份信息。

本 MVP 不做导入测试，因为当前契约不承诺导入、自动合并或云端恢复。界面不得把“已导出”写成“已备份到云端”。

## 六、与学习证据隔离的回归检查

分别在无笔记、有一张“我的理解”、有一张“待核对”、存在错误笔记和删除全部笔记五种状态下，重跑相同的合成学习流程。以下输出必须完全一致：

- 课前诊断题分、公开四态、错因和 recommended path；
- 自适应路线等级、建议顺序、`route_state` 与 `review_queue`；
- 正式题分、反馈、复述结果和 `mastery`；
- 延迟测量资格、配对规则和统计输入。

任何差异都视为阻塞问题。笔记可以在阅读界面显示，但不得作为这些函数的参数，也不得被拼入模型评分提示词。

## 七、界面与可访问性验收

- “我的理解”和“待核对”同时有文字标签，不能只靠颜色区分；
- 每张卡片显示“创建时位置，不代表已核验”的短说明或可访问辅助文本；
- 创建、编辑、取消、删除和导出可用键盘完成，焦点不会在关闭编辑器后丢失；
- 删除有明确目标和确认，删除中禁用重复提交；
- 本地保存、未记录位置、导出成功和失败状态通过可访问状态区域播报；
- 窄屏下正文、位置与操作不会互相遮挡；
- 账号切换时旧账号卡片不闪现；
- 全部公开文案中没有“论文事实”“已验证正确”“掌握”或因果提升承诺。

## 八、进入实现与发布的验收门槛

1. 18 个合成场景全部通过，且失败用例不会产生事实徽标或伪造位置；
2. 数据模型和公开类型中不存在 `paper_claim`、`verified` 或评分字段；
3. 来源快照五个内置位置与官方来源说明一致，但所有快照均明确不是核验证据；
4. 正文只来自用户输入，代码路径没有模型补写、自动纠错或自动补引用；
5. 账号切换、退出、单卡删除与导出经过双账号隔离测试；首版不提供清空全部；
6. 网络检查证明卡片正文与来源快照不发送到服务端；
7. 笔记有无、多少、内容和类型均不改变诊断、路线、正式评分、复述或延迟测量；
8. 导出不含秘密、隐藏答案、评分数据、账号内部键或其他账号卡片；
9. 桌面和窄屏完成键盘、焦点、删除确认和状态播报检查；
10. 未来官方 allowlist 云端版仍标为独立规划，没有用本地字段模拟已上线能力。

## 九、结论边界

上述验收通过只说明本地笔记卡能在合成场景下保存用户文字、记录创建位置、隔离账号并安全导出。它不能说明笔记正确、用户理解更好、学习效果提高或长期保持改善。真正的论文事实认证与云端同步需要新的服务端 allowlist、版本、权限和独立验证方案。
