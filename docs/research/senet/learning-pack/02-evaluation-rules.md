# SENet 第一次陪读｜评测与诊断规则

本文件不能提前展示给学习者。它用于人工评测第一轮实验，也将作为后续产品自动诊断功能的基准。

## 一、三个学习目标

### L1：理解问题与机制

学习者能够说明：

- 普通卷积中的通道依赖主要被隐式学习；
- SE 显式建模通道关系；
- 生成的是随输入变化的通道权重；
- 目标是重标定特征，不是固定删除通道。

证据：PDF 第 2—3 页，第 3 节开头和 3.2 节 Discussion。

### L2：理解张量形状

学习者能够正确说明：

```text
H×W×C
→ 1×1×C
→ C/r
→ C
→ H×W×C
```

证据：PDF 第 3 页公式（2）—（4）；第 4 页 Figure 2、Figure 3。

### L3：理解在 ResNet 中的插入位置

学习者能够说明：

- SE 作用于 non-identity residual branch；
- squeeze 和 excitation 位于与 identity 相加之前；
- 缩放后的 residual branch 再与 identity 相加。

证据：PDF 第 3 页 3.3 节；PDF 第 4 页 Figure 3。

## 二、题目 1 评分规则

题目：为什么 Squeeze 要把每个 `H×W` 通道压缩成一个数？这样做获得了什么，又丢失了什么？

满分 4 分：

| 得分点 | 分值 |
|---|---:|
| 说明全局平均池化为每个通道生成全局统计/描述 | 1 |
| 说明它让后续门控能够利用整幅特征图的上下文 | 1 |
| 说明输出保留 C 个通道而不是只剩一个数 | 1 |
| 说明具体空间位置和空间分布信息被压缩掉 | 1 |

诊断规则：

- 说“把 C 个通道平均成一个通道”：标记 `概念混淆-空间与通道`。
- 说“删除不重要通道”：标记 `概念混淆-重标定与剪枝`。
- 说“训练后每个通道都有一个固定权重”：标记 `概念混淆-静态与输入相关权重`。
- 只说“为了减少计算量”：标记 `遗漏-全局通道描述`。
- 没有提到空间信息损失：标记 `遗漏-聚合代价`，但不判整题错误。

回看位置：PDF 第 3 页，3.1 节和公式（2）。

## 三、题目 2 评分规则

题目输入：`32×32×256`，`r=16`。

标准过程：

```text
Squeeze：1×1×256
第一个 FC：256/16 = 16
第二个 FC + sigmoid：256
Scale 输出：32×32×256
```

满分 4 分，每个形状 1 分。

诊断规则：

- 写成 `32×32×16`：标记 `概念混淆-瓶颈维与特征图维`。
- 最终输出为 `1×1×256`：标记 `遗漏-Scale广播`。
- 最终输出为 `32×32×16`：标记 `概念混淆-SE改变输出通道数`。
- 将 `r=16` 理解为保留 16 个通道：标记 `概念混淆-reduction-ratio`。

回看位置：PDF 第 3 页公式（3）、（4）和 PDF 第 4 页 Figure 3。

## 四、题目 3 评分规则

正确答案：B。

满分 3 分：

| 得分点 | 分值 |
|---|---:|
| 选择 B | 1 |
| 说明 SE 缩放 residual/non-identity branch | 1 |
| 说明缩放发生在与 identity 相加之前 | 1 |

诊断规则：

- 选择 A：标记 `结构错误-SE插入位置`。
- 选择 B 但认为 identity 也经过 SE：标记 `概念混淆-残差双分支`。
- 认为先相加还是先 SE 完全等价：标记 `概念混淆-输入相关非线性门控`。
- 只凭记忆选择 B，无法说明两条分支：标记 `表述不清-缺少结构依据`。

回看位置：PDF 第 4 页 Figure 3。

## 五、复述评分规则

采用四维评分，每项 0—2 分，共 8 分。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 问题 | 没说或说错 | 提到通道重要性 | 说明显式建模输入相关的通道依赖 |
| Squeeze | 说错维度 | 提到全局池化 | 说明 `H×W×C → 1×1×C` 及全局描述 |
| Excitation/Scale | 没说或说错 | 提到生成权重 | 说明两层门控生成 C 个权重并逐通道缩放 |
| ResNet 接入 | 没说或说错 | 只说可以接入 | 说明 residual 分支先 SE、再与 identity 相加 |

判定：

- 7—8 分：本节理解通过；
- 5—6 分：基本理解，针对缺项追问一次；
- 3—4 分：存在明显缺口，回看对应原文后重新复述；
- 0—2 分：尚未形成机制理解，重新走严格轨。

## 六、典型错误复述与正式反馈

### 样例 A

错误复述：

> SENet 用全局平均池化把所有通道压成一个通道，然后挑出最重要的几个通道，接在 ResNet 输出之后。

诊断：

- `概念混淆-空间与通道`
- `概念混淆-重标定与剪枝`
- `结构错误-SE插入位置`

正式反馈：

> Squeeze 是分别压缩每个通道的空间维度，因此仍得到 C 个通道描述值，而不是一个通道。Excitation 为全部 C 个通道生成输入相关的连续权重，并不固定挑出几个通道。在 SE-ResNet 中，SE 作用于 residual 分支，并在该分支与 identity 相加之前完成缩放。请回看 PDF 第 3 页公式（2）—（4）和第 4 页 Figure 3。

### 样例 B

部分正确复述：

> SE 先对特征做全局平均池化，再经过两个全连接层得到权重，最后乘回原特征。

诊断：

- `遗漏-要解决的通道依赖问题`
- `遗漏-输入相关权重`
- `遗漏-ResNet插入位置`

追问：

> 这个权重为什么不是一组训练完成后固定不变的参数？放入 ResNet 时，它缩放哪一条分支？

### 样例 C

错误复述：

> Excitation 用 softmax 选出概率最高的通道，其余通道会被抑制。

诊断：

- `概念混淆-sigmoid与softmax`

正式反馈：

> 论文使用 sigmoid，并明确要求通道关系不是互斥的，因此多个通道可以同时获得较高权重。这里不是总和为 1 的通道竞争。请回看 PDF 第 3 页 3.2 节和公式（3）。
