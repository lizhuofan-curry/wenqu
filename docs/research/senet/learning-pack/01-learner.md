## 一、材料地图

### 论文要解决的问题

普通卷积会在局部感受野中同时融合空间信息和通道信息，但通道之间的依赖关系主要被卷积核隐式地学习。作者希望显式建模通道关系，让网络能够根据当前输入增强更有用的通道、减弱较少有用的通道。

原文位置：PDF 第 1—3 页，重点是第 3 页第 3 节开头。

### 核心方法

在原有卷积变换之后增加一个轻量的 SE block：

```text
特征图 U
→ Squeeze：每个通道压缩成一个全局描述值
→ Excitation：根据所有通道的描述生成 C 个权重
→ Scale：每个通道乘以自己的权重
→ 重新标定后的特征图 X~
```

原文位置：PDF 第 2 页 Figure 1；第 3 页公式（2）—（4）。

### 主要证据

- 在 ResNet、ResNeXt、VGG、BN-Inception 和 Inception-ResNet 等基础网络上加入 SE block 后，ImageNet 验证集错误率普遍下降。
- 以论文中的实现为例，ResNet-50 为 3.86 GFLOPs，SE-ResNet-50 为 3.87 GFLOPs；作者用它说明计算量增幅很小。
- SE-ResNet-50 的参数量约比 ResNet-50 增加 10%，作者还讨论了移除最后阶段 SE block 以减少参数的方法。
- 论文还在 Places365 场景分类和 COCO 目标检测上进行了验证。

原文位置：PDF 第 4—7 页，Table 2、Table 5、Table 6。

### 论文结论

SE block 是一个能够接入多种 CNN 架构的通道重标定单元。它通过输入相关的通道权重提高网络表示能力，而不是重新设计一套完整的主干网络。

原文位置：PDF 第 8 页，第 7 节。

### 阅读时需要保持警惕的地方

- SE 不是把某些通道永久删除；权重会随输入变化。
- Squeeze 压缩的是空间维度，不是删除通道维度。
- Excitation 使用 sigmoid，不要求所有通道权重之和等于 1。
- 论文证明的是多个任务上的经验改进，并没有给出“通道为什么一定应该这样重标定”的完整理论证明。

## 二、严格轨：把 SE block 看成张量变换

假设卷积变换输出：

```text
U ∈ R^(H × W × C)
```

也就是共有 `C` 个通道，每个通道是一张 `H × W` 的特征图。

### 1. Squeeze：压缩空间信息

对第 `c` 个通道做全局平均池化：

```text
z_c = 1/(H×W) × Σ_i Σ_j u_c(i,j)
```

于是：

```text
H × W × C
→ 1 × 1 × C
```

每个通道由一个数概括。这个数提供该通道的全局统计，但会丢掉具体空间位置。

原文位置：PDF 第 3 页，3.1 节与公式（2）。

### 2. Excitation：学习通道之间的关系

把 `z` 输入两层全连接网络：

```text
s = sigmoid(W2 · ReLU(W1 · z))
```

如果 reduction ratio 为 `r`：

```text
C
→ C/r
→ C
```

第一层降维形成瓶颈，第二层恢复到 `C` 个权重。ReLU 提供非线性，sigmoid 把每个通道的门控值映射到 0—1。

论文特别要求这种门控不是互斥的：多个通道可以同时获得较高权重。因此这里不是 softmax。

原文位置：PDF 第 3 页，3.2 节与公式（3）。

### 3. Scale：逐通道缩放

第 `c` 个输出通道为：

```text
X~_c = s_c × u_c
```

`s_c` 是一个标量，它会乘到第 `c` 个通道的所有空间位置上。输出形状不变：

```text
H × W × C
→ H × W × C
```

原文位置：PDF 第 3 页，公式（4）。

### 4. 接入 ResNet 的位置

在 SE-ResNet 中，SE 操作位于残差分支内部：

```text
输入 x
├──────────── identity ────────────┐
└→ residual transform → SE scale ─┤
                                  ↓
                               相加输出
```

也就是说，先缩放残差分支，再与 identity 分支相加。

原文位置：PDF 第 4 页 Figure 3 与 3.3 节。

## 三、陪读轨：黄风教练版

先别被名字唬住。SE 干的事可以压成一句话：

> 卷积已经提取出一摞特征图，SE 再看一眼当前输入，决定这一摞里哪些通道该大声说话、哪些先小点声。

`Squeeze` 不是把通道扔掉，而是给每个通道写一张“一句话摘要”。原来每个通道有 `H×W` 个数，现在先平均成一个数，所以最后得到 `C` 个通道摘要。

接着 `Excitation` 把这 `C` 个摘要放在一起判断。这里不能只看一个通道自己，因为作者要学的是“通道之间的依赖关系”。两层全连接先压到 `C/r`，再拉回 `C`，最后给每个通道发一个 0—1 的音量旋钮。

然后就很朴素了：

```text
原通道 × 自己的音量旋钮
```

注意，旋钮不是永久焊死的。同一个通道遇到不同图片时，权重可以不同。你要是把它理解成固定剪枝，那就绕偏了。

放进 ResNet 时也别把两条路搅一锅：SE 调整的是 residual 分支，调完以后才和 identity 相加。看 PDF 第 4 页 Figure 3，箭头位置已经画得很清楚。
