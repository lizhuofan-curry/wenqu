# SENet 第一次陪读｜证据笔记卡本地 MVP 契约

> 适用范围：内置 SENet 阅读材料中的本机笔记卡。
>
> 核心边界：本 MVP 不认证论文事实。卡片只保存学习者自己写下的“我的理解”或“待核对”，来源字段只是创建时的位置快照。

## 一、目标与非目标

本 MVP 让学习者在阅读 Squeeze、Excitation、Scale 和 SE-ResNet 插入位置时，保存一段自己的文字，并在之后回到创建笔记时所在的材料位置。

本 MVP 不做以下事情：

- 不提供 `paper_claim`、`verified`、`correct` 或同义状态；
- 不把任何卡片称为“论文事实”“已由论文证明”或“正确答案”；
- 不调用模型补写、改写、纠错、摘要、拆分或补引用；
- 不把笔记内容、类型、数量或打开次数送入课前诊断、正式评分、复述评分、自适应路线、掌握度或延迟测量；
- 不上传、云同步、跨设备恢复或与其他账号共享笔记；
- 不根据笔记推断能力等级、长期掌握、迁移、保持或学习效果。

“证据笔记卡”中的“证据”只表示学习者可以保留文字及其阅读位置，方便日后自行回看；它不表示系统已经验证文字与论文一致。

## 二、两种内容类型

| `content_kind` | 界面标签 | 含义 | 不表示 |
|---|---|---|---|
| `learner_statement` | 我的理解 | 学习者此刻用自己的话写下的理解、解释或记忆 | 正确、完整、已核验或已掌握 |
| `question_or_hypothesis` | 待核对 | 学习者想进一步确认的问题、猜想、疑点或不确定表述 | 错误，也不表示系统将自动核对 |

类型由学习者显式选择。系统不得根据关键词、语气、confidence、题分或阅读行为自动判断或改换类型。

即使“我的理解”与官方论文完全一致，它在本 MVP 中仍是学习者陈述；即使“待核对”后来被学习者认为正确，系统也不得自动把它改成论文事实。学习者可以手动修改文字或类型，但修改仍不产生核验状态。

## 三、本地数据契约

每张卡片至少保存：

```text
schema_version = 1
id
owner_id
material_id
material_title
material_revision（可选）
section_id
section_title
content_kind = learner_statement | question_or_hypothesis
status = not_applicable | pending
content
source（可选）
created_at
updated_at
```

字段约束：

- `id` 在当前账号命名空间内唯一；
- `owner_id` 只用于本机隔离，取稳定登录用户 ID 或 `anonymous`，不得使用邮箱、访问令牌、密码或完整认证对象；
- `content` 只保存学习者显式输入的文字，首尾空白不被擅自改写，但去除首尾空白后必须非空，长度上限为 2000 个字符；
- `content_kind` 只接受上述两个值，未知值不得按“我的理解”兜底展示；
- `status` 由内容类型确定：我的理解为 `not_applicable`，待核对为 `pending`，不表示正确性；
- `created_at` 首次保存后不变，编辑只更新 `updated_at`；
- 本地存储键包含 schema 版本前缀与编码后的账号命名空间，不能使用全站共享的无账号键。

本 MVP 没有以下字段：

```text
paper_claim
verification_status
verified_at
verification_method
score
misconception_codes
mastery
route_action
```

不能用前端常量、默认值或隐藏字段假装这些能力已经存在。

## 四、来源只是创建时的位置快照

`source` 是创建时的未认证位置快照，当前实现只允许以下可选字段：

```text
label
detail
excerpt
locator
material_revision
```

规则如下：

1. 创建卡片时从当前阅读位置复制 `label/detail`；之后滚动或切换章节不能改写既有快照。
2. 没有可靠来源时不保存 `source`，界面显示“未附原文定位（普通学习笔记）”，不得猜测页码、公式或图片。
3. 材料删除时保留卡片并标记“原材料已删除”；章节或 revision 不匹配时单独标记“原位置可能已变化”，不自动重映射。
4. 来源快照不能触发“正确”“已核验”或“论文事实”标签；即使 `detail` 中出现页码或公式号，也不证明笔记内容正确。

当前内置 SENet 阅读器通过已有 `SourceRef` 提供 `label` 与自由文本 `detail`，并用 `map:*`、正文 section id 或 `result:*` 保存界面位置。`excerpt`、`locator` 和 `material_revision` 已列入安全白名单，但当前界面不主动生成结构化 PDF 页、论文页、公式或 Figure 字段。

结构化页码、公式、Figure 与创建时刻定位属于未来增强；在实现并逐项验证前，不得把它们写成首版已捕获能力。学习者端也不得通过笔记入口获得 `02-evaluation-rules.md` 或 `05-prestudy-evidence-map.md` 中的隐藏评分细则。

## 五、禁止自动补事实

保存、展示、编辑与导出全过程都必须遵守：

- 不把“SE 会删掉不重要通道”静默改成“SE 会重标定通道”；
- 不自动补上 `1×1×C`、`C/r`、`C` 或 Scale 输出形状；
- 不自动补 sigmoid、softmax、residual、identity、公式号、Figure 号或因果解释；
- 不把一句混合正确与错误的文字拆成“已验证部分”和“错误部分”；
- 不使用课前诊断、正式评分、错因、复述、confidence、自适应路线或“已理解”点击替学习者生成卡片；
- 不把模型生成内容当成其自身正确性的证明；本 MVP 不提供模型建议入口；
- 不根据来源位置给出答案提示，尤其不得在课前诊断提交前泄露隐藏评分规则。

允许的系统动作仅限确定性的表单校验、账号隔离、位置快照、时间戳、排序、删除、筛选和导出。

## 六、账号命名空间与本地持久化

- 每次读取、创建、编辑、删除和导出都必须先确定当前账号命名空间；
- 账号 A 的本地卡片不能出现在账号 B 的列表、数量、搜索、导出或最近记录中；
- 退出登录后界面必须清除内存中的卡片状态。再次登录同一账号可读取该账号在同一浏览器中的本地数据；
- 同一账号换浏览器、换设备、清除站点数据或使用隐私模式时，不承诺恢复；
- 本 MVP 不向服务端发送卡片正文或来源快照，也不建立数据库表、同步队列或恢复任务；
- 删除只删除当前账号命名空间内的目标卡片；首版不提供“清除全部”。未来若增加该入口，必须二次确认并明确不可从云端恢复。

本地保存不是备份。界面应明确提示：“笔记仅保存在这台设备的当前浏览器中，请按需导出备份。”

## 七、导出契约

导出为 UTF-8 JSON，顶层包含：

```text
schema_version
exported_at
notes[]
```

每条 `notes[]` 由白名单重建，保留 `id`、材料与章节标识、内容类型、`status`、`content`、可选 `source` 和时间戳；`owner_id` 会在导出前移除。导出不得包含：

- 邮箱、访问令牌、密码、完整认证对象或数据库地址；
- 课前原始答案、隐藏评分细则、标准答案或 scorer/rubric 内部实现；
- 正式题分、错因、复述、掌握度、路线状态或其他用户档案；
- 其他账号的卡片或账号命名空间内部键。

文件名可包含材料短名与导出日期，但不得包含邮箱或其他直接身份信息。本 MVP 只承诺导出，不承诺导入、云端恢复或自动合并。

## 八、允许与禁止的产品文案

允许：

- “我的理解”
- “待核对”
- “记录于 Squeeze｜PDF 第 3 页｜公式（2）”
- “这是创建笔记时的位置，不代表内容已经核验。”
- “笔记仅保存在当前浏览器，可导出备份。”

禁止：

- “论文事实”
- “已验证正确”
- “AI 已帮你补全并核对”
- “你的笔记证明你已掌握 SENet”
- “根据这条笔记，你应该跳过本节”
- “笔记功能提高了你的学习成绩”

## 九、未来官方 allowlist 云端版

未来若要支持真正的 `paper_claim + verified`，必须作为独立版本设计，不得把本地 MVP 的“我的理解”批量改名为论文事实。新版本至少需要：

- 服务端维护官方论文原子主张 allowlist 与来源 revision/fingerprint；
- 逐条主张的 PDF 页、论文页、section、公式或 Figure 定位；
- 服务端独占的核验状态和版本失配 fail-closed；
- 用户所有权、数据库 RLS、同步冲突、删除、恢复与审计契约；
- 与隐藏评分规则隔离的公开 DTO；
- 对已有本地卡片进行用户主动、逐条、仍为待核对的迁移流程。

在这些条件完成并单独验收前，云端、官方 allowlist、事实认证和跨设备同步都只能写为未来规划。

## 十、有效性声明

本地笔记卡只支持外化当前想法与返回阅读位置。它不能判断文字真假，也不能证明理解、掌握、保持、迁移或学习提升。后续观察到笔记用户与非笔记用户的差异，也不能直接归因为笔记功能。
