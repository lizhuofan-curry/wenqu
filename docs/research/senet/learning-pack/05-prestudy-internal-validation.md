# SENet 第一次陪读｜课前诊断内部演练

演练对象：`senet-prestudy-v1`

> 本文件只使用合成作答特征，不包含真实用户答案。它验证评分与路由规则是否能稳定执行，不证明真实题目区分度或个性化路线的因果效果。

## 演练前检查

- 三道题分别对应 L1、L2、L3，没有用总分替代目标证据。
- 学习者端看不到标准答案、评分点、错因匹配细则和本文件。
- 信心必填但不计分，也不改变本版路线；高信心错误与低信心正确只保留为未来研究观察。
- 空白与无法解析使用 `insufficient`，不伪装成明确错误。
- 所有事实只引用官方 CVPR 2018 论文第 3 节、公式（2）—（4）和 Figure 1—3。

## 预期反馈边界

- 场景 1、11 只能说“本节三个目标均已展示课前证据”，不能说“已经掌握 SENet”。
- 场景 5—8、10 可以指出对应题目中出现了相反证据，但不能扩展为总体能力判断。
- 场景 9、12、13 必须使用“尚无充分证据”，不能把未作答写成概念错误。
- 所有场景在正式学习前只返回目标状态和路线理由，不返回标准答案或完整纠正文本。

## 结构自检

- [x] 明确三个 SENet 第 3 节学习目标。
- [x] 每题支持 `0/1/2/insufficient`。
- [x] confidence 必填但不计分、不改变本版路线，并覆盖高信心错误与低信心正确的未来观察边界。
- [x] 证据地图包含 source、allowed inference 与 forbidden inference。
- [x] 路由按目标与关键混淆决定，不输出能力等级。
- [x] 至少覆盖正确、部分正确、错误、空白、关键词复制、重复提交和版本变化。
- [x] 至少 10 种内部演练；当前共 18 种。
- [x] 首版只适用于内置 SENet。
- [x] 没有真实用户答案、密钥、令牌或数据库连接信息。
- [x] 没有把合成演练写成学习效果或因果验证。

## 结论

规则级演练通过，可以进入实现前评审。进入真实用户测试前，仍需验证题面是否易懂、不同基础学习者是否能完成、路线建议是否被接受，以及课后异题与次日迁移是否提供更强证据。
