## 三、逐题隐藏评分

每题采用 `2 / 1 / 0 / insufficient` 四态。`insufficient` 是独立状态，不折算为明确错误。

### P1（L1）

- `2`：明确否定永久删除，说明权重随当前输入生成、并非训练后固定参数，并说明 Scale 将权重乘回对应通道而不改变原特征形状。
- `1`：判断方向正确，但只说明“调整重要性”，或缺少输入相关、非剪枝、Scale 乘回原通道中的一个或多个关键边界。
- `0`：明确认为权重固定、通过 softmax 竞争，或永久删除部分通道。
- `insufficient`：空白、无法解析、只复述题干或没有形成可判断陈述。

可触发标签：`静态与输入相关权重`、`重标定与剪枝`、`sigmoid与softmax`。

### P2（L2）

- 每个阶段作为一个证据点：`1×1×64`、`4`、`64`、`14×14×64`。
- `2`：四个证据点全部正确。
- `1`：两个或三个证据点正确，且没有把最终通道数明确解释成只保留 4 个通道。
- `0`：零或一个证据点正确，或明确把瓶颈维当成永久输出通道数。
- `insufficient`：空白、只有原始输入，或内容无法对应四个阶段。

可触发标签：`空间与通道`、`瓶颈维与特征图维`、`Scale广播`、`reduction-ratio`、`SE改变输出通道数`。

### P3（L3）

- `2`：在相加前对 residual 输出使用 `se()`，并明确 identity 不经过 SE。
- `1`：位置正确但没有说明双分支，或能说明 residual 分支但伪代码位置表述不完整。
- `0`：相加后才使用 SE、让 identity 经过 SE，或声称两种位置完全等价。
- `insufficient`：空白、只抄伪代码或没有给出可判断位置。

可触发标签：`SE插入位置`、`残差双分支`、`输入相关非线性门控`。

## 四、信心字段

- 取值：`low / medium / high`，对应“不确定 / 比较确定 / 很确定”。
- 信心字段为必填，仅记录学习者对当前回答的自我判断。
- 信心不进入题分、总分、目标状态或本版路线；不得用低信心扣分，也不得用高信心加分。
- `high + 0` 与 `low + 2` 可作为未来研究的观察维度，但本版界面和路线不得声称已经使用这些组合做决定。
- 缺少或非法信心值时，请求校验失败；不得自行补值后继续评分。

## 五、目标状态与路线映射

目标状态直接取对应题目的证据态，不把三题简单平均成能力等级：

| 题目状态 | 目标状态 |
|---|---|
| `2` | 已展示证据 |
| `1` | 部分证据 |
| `0` | 出现相反证据 |
| `insufficient` | 尚无充分证据 |

路由先把目标状态归为：`ready = 2`、`partial = 1`、`severe = 0/insufficient`。其中 `0` 表示相反证据，`insufficient` 表示证据不足，两者必须保留各自公开状态，不得在反馈中混写。

1. **完整学习**：出现任一 critical conflict，或 `severe` 目标达到两个及以上。critical conflict 包括永久剪枝或训练后固定通道权重、把瓶颈维当成 Scale 后最终通道数、在 residual 与 identity 相加后再门控、或让 identity 分支经过 SE。
2. **聚焦学习**：不满足完整学习条件，且存在任一 `partial`，或恰有一个 `severe`；从依赖顺序中最早未满足目标开始，并保留其他目标的快速复核。
3. **精简复核**：三个目标均为 `ready`；允许缩短重复解释，但不能跳过课后同目标异题与复述。
4. **人工选择优先**：`recommended_path` 只是可撤销的建议浏览顺序，不是跳过内容的许可或要求。学习者可以随时回到材料地图、任意章节或完整路线。

依赖顺序默认 `L1 → L2 → L3`。如果只有 L3 缺口，可直接聚焦残差双分支；如果 L1 出现关键混淆，即使总分较高也应从机制边界开始。

## 六、允许与禁止的产品陈述

允许：

- “你在 L2 的这道课前题中已经展示了完整形状推导。”
- “目前尚无充分证据判断 L3，建议先看残差双分支。”
- “本次为你缩短了已展示证据的部分，并保留快速复核。”

禁止：

- “你是 SENet 高级学习者。”
- “AI 已准确测出你的深度学习水平。”
- “三题全对证明你已经掌握 SENet。”
- “个性化路线使你的成绩提高。”
- “空白说明你不懂。”

## 七、服务端记录最小字段

```text
diagnostic_version
rubric_fingerprint
scorer_fingerprint
material_id
material_revision
learning_objective_id
item_id
raw_answer
evidence_state
score_0_1_2_or_null
misconception_codes
confidence
route_action
evaluator
completed_at
```

- `insufficient` 时 score 应保存为 `null`，避免和明确的 `0` 混淆。
- `rubric_fingerprint` 覆盖题面、公开/隐藏证据契约、来源与声明式路由规则。
- `scorer_fingerprint` 是按固定顺序拼接三个实际 scorer、判定辅助函数、摘要函数与总评函数源码后计算的 SHA-256；服务端必须比较请求记录、当前 rubric 与当前 scorer 的 fingerprint，任一不一致均 fail closed，不得评分或复用旧路线。
- 原始答案不得进入公开分析、演示数据或日志。
- 客户端不能提交 evidence_state、分数、标签或 route_action 作为服务端真值。
- 首次提交形成课前基线；重复提交不得静默覆盖基线。

## 八、有效性声明

本规则提供的是目标级内容路由，不是经过心理测量学验证的能力量表。三道题的合成演练只能验证规则可执行，不能证明题目区分度、路线有效性或学习提升。首版应结合课后同目标异题、次日迁移与真实用户反馈继续验证；任何因果主张均需额外研究设计支持。
