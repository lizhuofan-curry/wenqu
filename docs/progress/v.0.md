# 知隅｜v.0 项目记录

记录日期：2026-07-27  
版本状态：本地与 GitHub 验收通过

## 本版本目标

把最初产品构想中的基础核心做成一套真实前后端产品：

```text
材料地图
→ 严格轨与陪读轨
→ 三道理解题
→ 用户复述
→ 错因诊断
→ 阅读档案
```

首份内置材料为 CVPR 2018 论文 *Squeeze-and-Excitation Networks*。

## 已实现

### 产品架构与设计

- 明确“原文证据 + 陪读表达 + 主动回忆 + 错因档案”的产品定位；
- 明确严格轨与陪读轨的数据边界；
- 完成首页、学习流程、诊断和档案的信息架构；
- 完成深色阅读空间、暖金与薄荷绿的视觉系统；
- 完成三种陪读人格及其表达边界；
- 完成可演进到用户系统、云存储和移动客户端的技术架构。

### 前端

- 阅读室首页；
- SENet 材料卡片；
- PDF / Markdown 上传入口；
- 黄风教练、安静师姐、严格研究员选择；
- 问题 / 方法 / 证据 / 结论 / 局限材料地图；
- 严格轨与陪读轨双栏阅读；
- 三道理解题；
- 3—5 句复述；
- 掌握度、逐题反馈、错因和原文位置；
- 阅读档案；
- 桌面端与小屏响应式布局。

### 后端

- 材料、人格、学习会话和阅读档案 API；
- 内置 SENet 内容与隐藏评分规则；
- 可重复的 SENet 规则评分；
- SQLite 持久化；
- PDF / Markdown 格式和大小校验；
- 文本型 PDF 页码标记；
- OpenAI Responses API + Pydantic 结构化输出；
- 额度、密钥、网络、频率和请求错误的用户友好提示；
- 前端不接触 `OPENAI_API_KEY`。

### 工程与仓库

- `apps/web`、`services/api`、`docs`、`resources` 分类结构；
- 根目录一条命令启动和一条命令检查；
- `.env.local`、PDF、数据库、构建产物和缓存忽略规则；
- 中英文产品 README 与真实页面截图；
- GitHub Actions CI；
- Dependabot 依赖更新检查；
- 版本进度与自动更新工作流。

## 已知问题

1. OpenAI 项目返回 `insufficient_quota`，自定义材料暂时不能生成；内置 SENet 不受影响。
2. 当前没有用户登录和多人数据隔离。
3. 扫描 PDF 暂不支持。
4. 本地 SQLite 适合验证，不适合作为正式多用户生产数据库。
5. 尚未补齐线上监控、备份、隐私协议、用户协议和账号删除。

## v.0 不包含

- OCR、复杂公式和表格版面恢复；
- TTS、RVC 或真人音色；
- 社区、角色市场和世界观联动；
- 支付与订阅；
- 应用商店提交。
