# 问渠 v.2｜云端账号与跨设备记录基础版

日期：2026-07-27

## 本版目标

把 v.1 的浏览器本地档案升级为可上线的真实账号和云端学习记录，同时保留无配置时可运行的公开演示模式。

## 已完成

- 引入 Supabase 官方浏览器客户端；
- 增加真实邮箱注册、邮箱确认、密码登录、会话保持和退出登录；
- 增加友好的账户错误提示，密码仍不会由问渠明文保存；
- 增加本地记录登录后自动迁移到云端；
- 完成练习后同时保存本机备份和用户隔离的云端记录；
- 阅读档案登录后优先读取云端数据；
- 增加 `profiles` 与 `study_records` 数据库结构；
- 为两张表启用 Row Level Security，用户只能访问自己的数据；
- 增加 Supabase 部署、回调地址、安全边界和跨设备验收文档；
- 保持无 Supabase 环境变量时的本地演示回退。
- 已通过 Vercel Marketplace 创建并连接 `supabase-aureolin-button`；
- 已在生产数据库执行首个用户隔离迁移；
- 已部署到 `https://wenqu-reading-room.vercel.app`；
- 已创建 GitHub 草稿 PR #18，并通过前后端 CI。
